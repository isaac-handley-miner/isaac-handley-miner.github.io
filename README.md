# Personal Academic Website

A clean, single-page academic website built with plain HTML and CSS. Hosted on GitHub Pages.

## Updating Content

Edit `index.html` to update your bio, CV, or publications. The file contains clear section comments and copy-paste templates for adding new entries.

## Deploying Changes

```bash
git add .
git commit -m "Describe your change"
git push
```

The site updates automatically within a couple of minutes.
